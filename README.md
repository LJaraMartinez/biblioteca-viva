# BibliotecaViva - Sistema de Gestión y Reservas

Este repositorio contiene la solución informática y documentación para la Evaluación 3 de Ingeniería de Software.

## Estructura del Repositorio

- `/docs`: Documentación, requisitos, trazabilidad y casos de prueba.
- `/src`: Código fuente de la aplicación.
- `/tests`: Pruebas de software.

## Cómo empezar

1. Clona este repositorio:
   `git clone <URL_REPO>`
2. Crea tu propia rama de trabajo antes de editar:
   `git checkout -b feature/nombre-tarea`
3. Lee el manual en `/docs` para ejecutar la aplicación.
